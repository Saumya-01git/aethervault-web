# 🎨 AetherVault Web Client

Frontend Web Client for **AetherVault** — a cloud-based media file storage and sharing web application (Google Drive clone).

## 🚀 Tech Stack
- **Framework**: React + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **API Client**: Axios

## 🛠️ Quick Start

```bash
# Install dependencies
npm install

# Set up local environment variables
cp .env.example .env.local

# Start development server
npm run dev
```

The web app will start at `http://localhost:5173`.
